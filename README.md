# Управление арендной недвижимостью

Личный сайт для управления квартирами в Москве, Минске и Дубае: аренда, поступления, расходы, налоги, документы и финансовый результат.

Проект начинается с [концепции продукта](docs/CONCEPT.md). В ней описаны первая версия, основные сценарии, финансовая модель и дальнейшее развитие.

Текущий этап: проектирование. Приложение пока не реализовано.
